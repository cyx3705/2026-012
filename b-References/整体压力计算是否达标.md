# 整体压力计算是否达标

## 结论

以图纸标注的最大垂直高差 **349 mm** 计算，海霖科技 D15L-BA2 泵的标称正压上限为 **+40 kPa**，可提供的理论静态扬程约 **4.08 m**。因此，若需要将液体从下部容器送至上部容器并克服 349 mm 高差，**静压条件满足，能够升液**。

静压需求为约 **3.42 kPa**；相对 +40 kPa 的上限，尚有约 **36.6 kPa**（约 **3.73 m 水头**）可用于管路、环形流道、滤层、弯头和阀件产生的压损。

| 泵型号 | D15L-BA2 | `海霖科技泵组数据.jpg` |
| 泵标称压力范围 | -40～+40 kPa | `海霖科技泵组数据.jpg` |
| 泵标称流量 | 3.0 L/min | `海霖科技泵组数据.jpg` |

计算将冷萃液近似为水：密度 `ρ = 1000 kg/m³`，重力加速度 `g = 9.80665 m/s²`。冷萃液密度即使取 `1020 kg/m³`，结论也不变。

## 静压计算

液柱静压：

```text
Δp = ρ × g × Δh
   = 1000 × 9.80665 × 0.349
   = 3422 Pa
   ≈ 3.42 kPa
```

泵在 +40 kPa 下对应的理论水头：

```text
H = Δp / (ρ × g)
  = 40000 / (1000 × 9.80665)
  = 4.079 m
  ≈ 4.08 m
```

| 比较项 | 数值 |
| --- | ---: |
| 升液所需静压 | 3.42 kPa |
| 泵标称正压上限 | 40.0 kPa |
| 静压余量（按上限估算） | 36.58 kPa |
| 静态扬程余量 | 4.079 - 0.349 = 3.730 m |
| 压力上限与需求之比 | 约 11.7 倍 |

## 工程判定边界

本结论仅证明静态升液高度满足，不能直接保证在 **3.0 L/min** 时仍有 +40 kPa 压差。铭牌中的 3.0 L/min 与 +40 kPa 通常分别接近自由流量和堵转压力，实际运行应以该泵的压流曲线或实测值为准。

目标流量下的判定式为：

```text
泵在目标流量下的实际压差
  > 3.42 kPa（静压） + 管路压损 + 环形流道压损 + 滤层压损 + 局部件压损
```

在“目标流量下仍可提供 +40 kPa”的乐观假设中，除静压外允许的总压损上限约为 **36.6 kPa**。实际可用余量须改用泵在目标流量点的实际压差重新计算。

`-40 kPa` 是抽吸侧负压能力的标称值，不应与出液侧的 `+40 kPa` 相加作为扬程；本升液判断使用的是出液侧正压。

若系统为已灌满的封闭循环回路，稳定运行时上下行液柱的部分静压可以相互抵消；但首次起液、两端液面存在 349 mm 高差，或上部容器相对下部容器有额外气压时，仍应按以上静压及附加压差校核。
